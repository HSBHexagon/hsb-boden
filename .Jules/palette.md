## 2026-08-15 - Adding Visual Required Indicators to CSS Grid Forms
**Learning:** When adding inline visual indicators (like required asterisks) to form labels that utilize CSS grid layouts, simply appending the element to the label causes the grid to treat the text node and the new element as separate grid items, breaking the intended layout (e.g., pushing the input to the next row).
**Action:** Always wrap the label text and the new visual indicator within a common `<span>` container to ensure they are treated as a single grid item and remain on the same line, preserving the layout integrity. Ensure to use `aria-hidden="true"` for purely visual indicators when native validation attributes like `required` are already present to prevent redundant screen reader announcements.
