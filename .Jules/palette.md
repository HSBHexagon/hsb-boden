## 2026-08-05 - Form Accessibility
**Learning:** Native CSS Grid with labels and asterisks forces them into separate rows unless wrapped in a `<span>`. Adding explicit focus-visible classes ensures keyboard accessibility is immediately apparent.
**Action:** Always wrap label text and required asterisks in a container (e.g. `<span>`) inside grid layouts, and explicitly apply `focus-visible` classes to all interactive form elements for robust accessibility in this codebase.
