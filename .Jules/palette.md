## 2024-07-29 - Accessibility and Visual Focus Enhancements for Form Elements
**Learning:** Native form focus states (outline) are often insufficient or stripped by Tailwind's resets. For accessible UX, explicitly applying a focus-visible ring (e.g., `focus-visible:ring-1 focus-visible:ring-hsb-red focus-visible:outline-none`) to interactive elements guarantees that keyboard users have a clear visual indicator. Additionally, sighted users benefit from an explicit required indicator (like a red asterisk with `aria-hidden="true"`) to know which fields are mandatory. In CSS Grid layouts, wrapping the label text and indicator in a `<span>` prevents awkward layout wrapping where the asterisk might be pushed to a new line or misaligned.
**Action:** When creating forms or interactive elements, always explicitly define focus states using Tailwind's `focus-visible` pseudo-class and ensure mandatory fields have clear, semantic visual indicators correctly scoped within layout wrappers like spans.
