## 2026-08-01 - Added explicit required indicators and focus-visible states
**Learning:** Native `required` attributes and default browser focus outlines are often insufficient for accessibility. While screen readers announce `required`, sighted users need a visual indicator (like a red asterisk with `aria-hidden="true"`). Furthermore, explicit `focus-visible` classes (e.g., Tailwind's `focus-visible:ring-1 focus-visible:ring-hsb-red focus-visible:outline-none`) guarantee a consistent, highly visible focus state across browsers for keyboard users.
**Action:** When working on form components, always explicitly check if visual indicators exist for required fields and explicitly define `focus-visible` styles on all interactive elements instead of relying on browser defaults.
