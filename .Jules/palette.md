
## 2024-08-10 - Explicit Focus and Required Indication in Form Grid Layouts
**Learning:** In CSS grid layouts used for forms, simply appending a required asterisk (e.g., `<span class="text-red-500">*</span>`) directly after text in a `<label>` can sometimes cause it to break onto a new line if not explicitly grouped. Wrapping the text and the asterisk in a `<span>` ensures they flow together. Furthermore, relying on native focus rings is often insufficient (or removed by CSS resets like Tailwind); interactive elements need explicit, high-contrast `focus-visible` utility classes (e.g., `focus-visible:ring-2 focus-visible:ring-hsb-red focus-visible:outline-none`) applied to every input, select, textarea, checkbox, and button to ensure consistent keyboard accessibility.
**Action:** When working on forms, always wrap the label text and required indicator in a `<span>` to protect the layout flow, and proactively apply explicit `focus-visible` classes to all interactive fields to guarantee keyboard navigability.
