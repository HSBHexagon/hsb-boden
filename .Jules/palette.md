## 2026-07-27 - Form Accessibility Micro-UX (Focus states and required fields)
**Learning:** When using CSS Grid for form layout in Astro components (like `LeadForm.astro`), appending visual indicators (e.g., `*`) inline to text nodes can break grid cell alignment or flow if not properly containerized. Also, native focus rings are often stripped or insufficient in this design system, requiring explicit `focus-visible` utility classes on all interactive elements. Screen readers don't need the `*` read out if `required` is present.
**Action:** When adding inline visual indicators within a grid layout, always wrap the main label text and the indicator together in a generic `<span>` container to preserve grid structure. Use `<span aria-hidden="true">` for visual-only indicators. Always add explicit Tailwind `focus-visible` states to interactive form elements to guarantee keyboard navigation accessibility.
