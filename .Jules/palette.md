## 2026-08-04 - Lead Form Required Indicators and Keyboard Focus
**Learning:** Native CSS Grid can break standard label layouts when adding inline visual elements (like `*`). Required fields in this design system must wrap the label text and indicator in a `<span>` container within the grid label to maintain layout. Additionally, native focus outlines are stripped/insufficient, so explicit Tailwind `focus-visible:ring-2 focus-visible:ring-hsb-red focus-visible:outline-none` classes must be manually added to all interactive elements to ensure reliable keyboard navigation.
**Action:** Always wrap label text in a `<span>` when appending inline indicators in grid contexts, and proactively add explicit Tailwind `focus-visible` ring utilities to all newly created or updated inputs, selects, and buttons.
