## 2024-07-30 - Accessible Visual Required Indicators and Focus States
**Learning:** When adding inline visual indicators (like a required `*`) to text labels within CSS grid layouts, the text and indicator must be wrapped in a container (e.g., `<span class="flex gap-1">`). Otherwise, the grid will treat them as separate elements and force them onto different rows, breaking the layout. Additionally, relying solely on native focus outlines is insufficient; explicit `focus-visible` utility classes (e.g., `focus-visible:ring-1 focus-visible:ring-hsb-red focus-visible:outline-none`) are needed for all interactive elements to ensure clear keyboard accessibility.
**Action:** When enhancing form components in Astro/Tailwind with grid labels, always explicitly wrap the text and any visual indicators. Always add specific `focus-visible` ring classes to interactive elements rather than relying on browser defaults.
