## 2026-09-21 - Added loading spinner to lead form submission
**Learning:** Adding a visible loading spinner to asynchronous form submissions significantly improves user experience by providing immediate feedback, especially for users on slower connections or when backend processing takes a noticeable amount of time.
**Action:** Always include a visual loading state (like a spinner and updated button text) for buttons that trigger asynchronous operations, ensuring users are aware that their request is being processed.
