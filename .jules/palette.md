## 2024-05-16 - Explicit Visual Indicators for Required Form Fields and Focus States
**Learning:** For users relying on keyboard navigation, native focus outlines are often insufficient or stripped by CSS resets, making it difficult to track focus in interactive elements like forms. Additionally, relying solely on HTML5 `required` attributes without visual cues (e.g., asterisks) reduces form clarity and accessibility for sighted users.
**Action:** When creating or updating form components (like `LeadForm`), always implement clear visual indicators for required fields (e.g., `<span class="text-hsb-red" aria-hidden="true">*</span>`) and explicit `focus-visible` states using Tailwind utility classes (`focus-visible:ring-2 focus-visible:ring-hsb-red focus-visible:outline-none`) on all interactive elements.
